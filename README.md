# React Redux E-Commerce

A responsive e-commerce web application built with React and Redux Toolkit. The project focuses on building a structured shopping experience with product browsing, product details, and cart management.

## Features
- Browse available products
- View individual product details
- Add products to the shopping cart
- Increase or decrease product quantity
- Remove products from the cart
- View the total cart amount
- Navigate between different pages using React Router
- Manage application state using Redux Toolkit
- Reusable React components
- Responsive user interface

## Technologies Used

- React
- Redux Toolkit
- React Redux
- React Router
- JavaScript
- HTML
- CSS
- Vite

## Project Overview

The application is built using React components and follows a structured approach for managing different parts of the interface.

Redux Toolkit is used to manage the application state, including cart-related data. React Router is used to handle navigation between pages such as the home page, product details, and cart.

## Getting Started

To run this project on your local machine:

1. Clone this repository from GitHub.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Install the required dependencies:

npm install

5. Start the development server:

npm run dev

6. Open the local URL provided by Vite in your browser.
